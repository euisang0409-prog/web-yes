# 화면 설계

## UI 요구사항 확인

### UI(User Interface) 정의
UI는 사용자가 화면에서 직접 보고 조작하는 모든 요소를 의미한다.

예시
- 색상
- 폰트
- 버튼
- 메뉴
- 아이콘
- 입력창

---

## UI 구성 요소

### 1. 시각적 디자인(Visual Design)

사용자가 화면에서 직접 보는 요소를 설계한다.

예시
- 색상
- 글꼴
- 아이콘
- 이미지
- 레이아웃

### 2. 상호작용 디자인(Interaction Design)

사용자의 행동에 대해 시스템이 어떻게 반응하는지 설계한다.

예시
- 버튼 클릭 시 화면 이동
- 로그인 실패 시 경고 메시지 출력
- 로딩 애니메이션 표시

### 3. 정보 구조(Information Architecture)

사용자가 원하는 정보를 쉽게 찾을 수 있도록 구성하는 설계이다.

#### 메뉴 구조

기능을 어떻게 나눌 것인지 정의한다.

예시
- 홈
- 검색
- 장바구니
- 마이페이지

#### 콘텐츠 분류

정보를 어떤 기준으로 묶을 것인지 정의한다.

예시
- 최신순
- 인기순
- 카테고리별

#### 화면 흐름

사용자가 어떤 순서로 화면을 이동하는지 설계한다.

예시

목록 → 상세 → 결제

---

## UX(User Experience) 정의

UX는 사용자가 서비스를 이용하면서 느끼는 전체적인 경험을 의미한다.

---

## UX 구성 요소

### 1. 사용성(Usability)

설명 없이도 얼마나 쉽게 사용할 수 있는가

예시
- 버튼 크기가 적절함
- 메뉴 위치가 직관적임

### 2. 유용성(Usefulness)

사용자가 원하는 기능을 제공하는가

예시
- 사용자가 요구한 기능 제공

### 3. 매력도(Desirability)

서비스가 얼마나 매력적으로 느껴지는가

예시
- 아이콘 디자인
- 폰트 디자인
- 전체적인 분위기

### 4. 접근성(Accessibility)

연령, 장애 여부, 환경에 관계없이 사용할 수 있는가

예시
- 고령자 사용 가능
- 장애인 사용 가능

### 5. 신뢰성(Credibility)

서비스를 믿고 사용할 수 있는가

예시
- 오류가 적음
- 광고가 과도하지 않음

---

## UI와 UX의 관계

### UI는 UX를 만드는 중요한 수단이다

사용자는 서비스 내부 구조를 보는 것이 아니라 화면을 통해 서비스를 경험한다.

예시
- 버튼
- 메뉴
- 입력창
- 색상
- 안내 문구

### 좋은 UI가 항상 좋은 UX를 보장하지는 않는다

화면이 예쁘더라도 사용하기 불편하면 좋은 UX가 아니다.

### 좋은 UX를 위해서는 전체 사용 흐름도 중요하다

단순히 디자인만 좋은 것이 아니라 서비스 이용 과정 전체가 편리해야 한다.

# UI/UX 표준

## UI/UX 표준이란

사용자가 웹사이트나 앱을 일관성 있고 편리하며 안전하게 사용할 수 있도록 정한 설계 원칙이다.

---

## ISO 9241-210

### ISO란

국제표준화기구(International Organization for Standardization)

### 적용 대상

사용자와 컴퓨터가 상호작용하는 시스템

---

## 사용자 중심 설계 6대 원칙

### 1. 사용자는 설계 과정 전반에 적극적으로 참여해야 한다

실제 사용자가 요구사항 수집부터 테스트까지 참여해야 한다.

### 2. 전체 사용자 경험을 고려해야 한다

기능뿐 아니라 정서적, 인지적 경험도 고려해야 한다.

### 3. 설계는 반복적으로 수행되어야 한다

피드백을 받고 개선하는 과정을 반복해야 한다.

### 4. 사용자와 환경을 기반으로 설계해야 한다

예시

- 병원 시스템 → 데스크톱 중심
- 배달 앱 → 스마트폰 중심

### 5. 다양한 분야 전문가가 협력해야 한다

참여 인력

- 기획자
- UI 디자이너
- UX 디자이너
- 개발자
- 관리자

### 6. 사용자 평가가 반드시 포함되어야 한다

개발자가 아닌 실제 사용자가 테스트해야 한다.

## 정의

## 목적

- 버튼 위치 확인
- 메뉴 위치 확인
- 정보 배치 확인
- 화면 이동 흐름 확인

## 특징

- 디자인보다 구조 중심
- 빠르게 제작
- 아이디어 검증 목적
