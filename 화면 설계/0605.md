# UI 요구사항 확인하기

## 1. 소프트웨어 개발을 위한 화면 표준 및 지침 확인

UI(User Interface)를 설계하기 전에 화면 구성, 사용성, 접근성, 일관성 등을 확보하기 위한 표준과 지침을 수집하고 분석해야 한다.

## 국가기관에서 제공하는 지침 수집 및 분석

국가기관에서 제공하는 공공 웹·앱 UIUX 가이드라인을 수집하여 다음 항목을 확인한다.

- 접근성(Accessibility)
- 정보 구조(Information Architecture)
- 색상(Color)
- 타이포그래피(Typography)
- 화면 구성(Layout)
- 사용자 경험(UX)

### 주요 기관

#### 과학기술정보통신부
- 정보통신 정책 및 디지털 서비스 관련 지침 제공
- 디지털 서비스 표준 및 UIUX 관련 정책 확인

#### 행정안전부
- 전자정부 서비스 구축 지침 제공
- 공공 웹사이트 및 모바일 서비스 설계 기준 제공

#### 한국인터넷진흥원(KISA)
- 웹 접근성 관련 가이드 제공
- 정보보호 및 사용자 편의성 관련 기준 제공

#### 공공누리
- 공공기관 콘텐츠 활용 기준 제공
- 공공 데이터 및 디자인 표준 활용 가능

### 수집 방법

1. 각 기관의 공식 홈페이지 접속
2. UIUX 관련 자료 검색
3. 가이드라인 및 표준 문서 다운로드
4. 프로젝트에 필요한 항목 분석 및 정리

## 국제 UIUX 표준 수집 및 분석

### ISO 9241-11 (사용성)

사용성이란 사용자가 특정 목표를 효과적이고 효율적으로 달성하고 만족할 수 있는 정도를 의미한다.

주요 평가 요소

- 효과성(Effectiveness)
- 효율성(Efficiency)
- 만족도(Satisfaction)

### ISO 9241-110 (인터페이스 설계 원칙)

대화형 시스템 설계를 위한 원칙을 제시한다.

주요 원칙

- 작업 적합성
- 자기 설명성
- 기대 일관성
- 학습 용이성
- 오류 허용성
- 사용자 제어성

### ISO 9241-171 (접근성)

고령자 및 장애인을 포함한 다양한 사용자가 시스템을 이용할 수 있도록 접근성 기준을 제공한다.

주요 내용

- 키보드 사용 지원
- 화면 낭독기 지원
- 색상 대비 확보
- 대체 텍스트 제공

### ISO 9241-210 (사용자 중심 설계)

사용자의 요구사항과 경험을 중심으로 시스템을 설계하기 위한 국제 표준이다.

#### 사용자 중심 설계 6대 원칙

1. 사용자를 명확하게 이해하고 설계한다.
2. 사용자를 설계 과정 전반에 참여시킨다.
3. 사용자 평가를 기반으로 설계한다.
4. 반복적인 설계 과정을 수행한다.
5. 사용자 경험 전체를 고려한다.
6. 다양한 전문가가 협력하여 설계한다.

## 플랫폼별 디자인 가이드라인 수집 및 분석

### Android Material Design

Google에서 제공하는 디자인 시스템

주요 특징

- 일관된 UI 제공
- 직관적인 사용자 경험
- 반응형 레이아웃 지원
- 접근성 고려

### Apple Human Interface Guidelines(HIG)

Apple에서 제공하는 디자인 가이드

주요 특징

- 단순성(Simple)
- 명확성(Clarity)
- 일관성(Consistency)
- 사용자 중심 설계

### Web Design Guidelines

웹 서비스 구축 시 고려사항

- 반응형 웹 지원
- 웹 접근성 준수
- 크로스 브라우징 지원
- 일관된 네비게이션 구조

## 분석 결과 정리

수집한 표준과 가이드라인을 비교 분석하여 프로젝트에 적용 가능한 항목을 도출한다.

### 분석 항목

 구분  분석 내용 
----------------
 사용성  사용자가 쉽게 사용할 수 있는가 
 접근성  다양한 사용자가 이용 가능한가 
 일관성  화면 구성과 동작이 일관적인가 
 효율성  작업을 빠르게 수행할 수 있는가 
 유지보수성  향후 수정 및 확장이 용이한가

UI 요구사항 확인 단계에서는 국가기관 가이드라인, 국제 표준, 플랫폼별 디자인 가이드를 수집하고 분석하여 사용자 중심의 화면 설계 기준을 마련해야 한다. 이를 통해 사용성, 접근성, 일관성 및 품질을 향상시킬 수 있다.
