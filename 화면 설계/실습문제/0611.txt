[문제 5] 사용자가 도서 검색을 하였으나 검색 결과가 존재하지 않는 오류(또는 예외) 상황이 발생했습니다. 웹 접근성(WCAG 2.1)의 오류 안내 원칙에 부합하도록 기획자가 시나리오에 작성해야 할 구체적인 시스템 처리 방식과 메시지 구성 요소를 서술하시오.

정답 : 단순히 "오류" 또는 에러코드만 보여주거나 색상만 바꾸는게 아니라, 사용자가 명확히 인지할 수 있도록
"검색 결과가 존재하지 않습니다" 라는 구체적인 원인 텍스트 메시지를 화면에 표시해야 한다.
또한 다른 검색어를 유도하거나 이전으로 돌아갈 수 있는 해결방법을 함께 제공해야 한다.


[문제 6] 사이트 맵(Site Map)을 시각적인 트리(Tree) 구조나 그림으로만 작성하지 않고, '메뉴 1', '메뉴 2', 'Description' 항목을 포함한 표(Table) 형태로도 병행하여 작성해야 하는 이유를 서술하시오.

정답 : 
트리 구조의 그림은 전체적인 계층 구조를 직관적으로 파악하는데 유리하지만, 각 하위 메뉴가 실제로 어떤 기능을 수행하는지,
어떤 화면 요소를 포함하는지에 대한 상세한 정보를 담기 어렵기 때문에 표 형태의 문서로 세부 내용을 명시하여 보완해야 한다.

[문제 7] 입력 필드가 많거나 절차가 복잡한 파일 업로드 화면 설계 시, 사용자의 입력 오류를 방지하고 서비스 이탈을 막기 위해 UI 시나리오상에 반드시 포함해야 하는 '화면 사용 도움 정보'의 구체적인 예시 2가지를 서술하시오.

정답 : 
1. 사용자가 화면을 이해하고 기능을 올바르게 사용할 수 있도록 제공하는 안내 문구, 도움말, 예시, 툴팁 등을 말한다.
2. 특히 입력 항목이 많거나 절차가 복잡한 화면에서는 도움 정보가 반드시 필요하다.
