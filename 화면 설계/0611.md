# 화면 설계

## 1. UI 요구사항 확인하기

### 1-1. UI/UX 개념

#### UI(User Interface)

* 사용자가 시스템과 상호작용하는 화면, 버튼, 메뉴 등의 시각적 요소

#### UX(User Experience)

* 사용자가 시스템을 이용하면서 느끼는 전체적인 경험

### UI/UX 구성 요소

* 시각적 디자인
* 상호작용 디자인
* 정보 구조
* 콘텐츠
* 사용성

### UI/UX 관계

* UI는 사용자가 보는 화면
* UX는 사용자가 느끼는 경험
* 좋은 UI는 좋은 UX를 제공하는 기반이 된다.

### UI/UX 표준

* ISO 9241-210 : 인간 중심 설계(HCD)
* WCAG 2.2 : 웹 접근성 가이드라인
* IEEE 830 : 소프트웨어 요구사항 명세서(SRS) 표준

# 유용성(Usability)

## 정의

사용자가 시스템을 활용하여 목표를 얼마나 효과적이고 효율적으로 달성할 수 있는지를 나타내는 척도

## 고려사항

사용자 모형과 개발자 모형의 차이를 최소화해야 한다.

### 사용자 모형(User Model)

* 사용자가 생각하는 시스템

### 개발자 모형(Developer Model)

* 개발자가 구현한 시스템

### 차이 발생 원인

* 제공 기능과 기대 목적 불일치
* 실행 결과와 사용자 의도 불일치

---

# 실행 차(Gulf of Execution)

## 정의

사용자가 달성하려는 목적과 실제 시스템 기능 사이의 차이

## 최소화 방법

### 사용 의도 파악

* 목표 분석
* 핵심 기능 강조

### 행위 순서 규정

* 단계 최소화
* 명확한 순서 제공
* 친숙한 흐름 제공

### 행위 순서대로 실행

* 직관적인 절차 제공
* 적절한 입력장치 사용
* 피드백 제공
* 취소 기능 제공
* 적절한 기본값 설정

---

# 평가 차(Gulf of Evaluation)

## 정의

사용자의 의도와 시스템 실행 결과 간의 차이

## 최소화 방법

### 빠른 피드백 제공

* 즉시 반응
* 처리 상태 표시

### 상태 변화 인식 가능

* 변경 사항 명확히 표시

### 결과 확인 가능

* 미리보기 제공
* 결과 확인 기능 제공
