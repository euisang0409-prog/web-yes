문제 1. V모델과 테스트 관계 설명

소프트웨어 개발 프로젝트에서 V모델(V-Model)을 적용하여 테스트를 수행하려고 한다.

다음 요구사항에 따라 답하시오.

조건

V모델이 무엇인지 작성하시오.

V모델(V-Model)은 소프트웨어 개발 생명주기 모델 중 하나로, 폭포수 모델을 확장한 형태이며 개발 단계와 테스트 단계를 V자 형태로 대응시켜 표현한 모델입니다.

왼쪽은 개발 및 설계 단계, 오른쪽은 테스트 단계로 구성되며, 각 개발 단계에 맞는 테스트를 수행합니다.

개발 단계와 테스트 단계가 서로 대응되는 이유를 작성하시오.

개발 단계와 테스트 단계가 서로 대응되는 이유는 각 개발 단계에서 작성된 결과물이 제대로 설계되고 구현되었는지 검증하기 위해서입니다.

다음 개발 단계에 대응하는 테스트를 모두 작성하시오.
요구분석 -> 인수 테스트
아키텍처 설계 -> 시스템 테스트
모듈 설계 -> 통합 테스트
구현 -> 단위 테스트
