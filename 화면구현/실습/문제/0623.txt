A. BEM 네이밍 가이드
BEM 규칙에 어긋나는 클래스명이 발견될 경우 감점 요인이 됩니다. 아래 규칙을 엄격히 적용하세요.

Block (독립적인 컴포넌트): 각 섹션의 최상위 부모는 하나의 독립된 블록입니다.

허용: .gnb, .hero, .features, .pricing

Element (블록에 종속된 하위 요소): 언더스코어 2개(__)로 연결합니다.

[중요] 3중 중첩 금지: 구조가 깊어지더라도 __를 두 번 이상 반복하지 마세요.

올바른 예: .gnb__link (O)

잘못된 예: .gnb__menu__item__link (X) ❌ 구조적 계층과 상관없이 블록 바로 아래의 엘리먼트로 취급해야 합니다.

Modifier (상태 및 버전 변형): 하이픈 2개(--)로 연결합니다.

수정자(Modifier) 클래스는 단독으로 사용할 수 없으며, 반드시 원본 클래스와 함께 선언해야 합니다.

올바른 예: <div class="pricing__card pricing__card--popular"> (O)

잘못된 예: <div class="pricing__card--popular"> (X) ❌ 스타일이 유실되거나 중복 코드가 발생합니다.

독립성 유지: 특정 블록의 엘리먼트를 다른 블록 내부에서 재사용하지 마세요. (예: .features 섹션 내부에 버튼이 필요하다고 해서 .hero__btn을 가져다 쓰면 안 됩니다. .features__btn을 새로 정의해야 합니다.)

B. HTML 구조 가이드
시맨틱 태그를 적절히 활용하여 웹 접근성과 가독성을 높인 웹페이지 구조를 설계하세요.

구조적 배치: 전체 페이지는 아래의 HTML 골격을 유지해야 합니다.

HTML
<nav class="gnb"> ... </nav>
<header class="hero"> ... </header>
<main>
  <section class="features"> ... </section>
  <section class="pricing"> ... </section>
</main>

텍스트 마크업: 각 섹션의 제목은 중요도에 따라 <h1>, <h2>, <h3>를 위계에 맞게 사용하세요.

목록 마크업: 메뉴 리스트나 혜택 리스트는 <ul>과 <li> 태그를 활용하세요.

C. CSS 스타일링 및 제약 가이드
웹페이지의 레이아웃 배치와 디자인 톤을 일관되게 유지하기 위한 명확한 스펙입니다.

레이아웃 제어: * 수평 정렬이나 격자 배치가 필요한 곳은 반드시 display: flex 또는 display: grid를 사용하세요. (float나 inline-block 사용 금지)

블록 자체에 바깥 여백(margin)을 주어 배치하지 마세요. 블록은 어디든 갈 수 있게 독립적이어야 하므로, 내부 엘리먼트 간의 간격(gap 등)으로 레이아웃을 조절합니다.

지정 색상 가이드 (Color Palette):

Primary Color (포인트 블루): #3498db

Dark Color (다크 네이비): #2c3e50 / #0f172a

Text Color (기본 본문 텍스트): #475569 또는 #64748b

Background Color: 흰색(#fff)과 연한 회색(#f8fafc)을 섹션별로 교차 적용하여 화면 영역을 구분하세요.

3. 섹션별 세부 요
   

   구사항
1) 상단 네비게이션 영역 (.gnb)
구조: 로고, 메뉴 4개, 우측의 무언가(버튼/링크)가 좌-우로 균등하게 배치된 구조

BEM 필수 적용: * 블록: .gnb

메뉴 중 첫 번째 항목('제품 기능')에는 현재 페이지를 뜻하는 활성화 수정자 적용 (.gnb__link--active)

2) 메인 히어로 영역 (.hero)
구조: 화면 중앙 정렬 구조. 거대한 메인 타이틀, 설명 문구, 그리고 나란히 배치된 2개의 버튼 그룹

BEM 필수 적용:

두 버튼은 배경색이 다릅니다. 하나는 파란색 배경의 강조 버튼(.hero__btn--primary), 다른 하나는 연회색 배경의 보조 버튼(.hero__btn--secondary)으로 구현하세요.

3) 기능 카드 섹션 (.features)
구조: 섹션 타이틀이 상단 중앙에 있고, 하단에는 3개의 카드 디자인이 가로로 나란히 배치된 Grid 구조 (3열 배치)

BEM 필수 적용:

블록: .features

하위 카드 요소: .features__item

카드 내부에는 아이콘 역할을 하는 이모지 영역(.features__icon), 카드 제목, 카드 설명글이 포함되어야 합니다.

4) 가격 플랜 섹션 (.pricing)
구조: 섹션 타이틀 아래에 2개의 요금제 카드(일반 플랜, 추천 플랜)가 가로로 배치된 구조

BEM 필수 적용

두 번째 카드인 '프로페셔널 플랜'은 추천 상품이므로, 카드 전체 테두리가 블루 컬러로 강조되고 살짝 더 크게 표현되는 수정자(.pricing__card--popular)를 적용하세요.

추천 카드 내부의 버튼 또한 다르게 강조되는 수정자(.pricing__action-btn--highlight)를 부여하세요.
