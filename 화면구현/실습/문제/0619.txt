결과 화면 설명
사진 카드가 여러 개 나열된 갤러리 페이지를 만드시오.
HTML 작성 조건

전체 영역을 감싸는 div를 만들고 클래스명은 gallery-container로 작성한다.
페이지 제목은 h1 태그로 작성한다.
카드 목록을 감싸는 div를 만들고 클래스명은 card-list로 작성한다.
각각의 카드는 div로 작성하고 클래스명은 card로 지정한다.
카드 안에는 img, h2, p, button을 작성한다.
카드는 3개 이상 작성한다. 예시 카드 내용:
사진 제목: 봄 풍경
설명: 따뜻한 봄날의 풍경입니다.
버튼: 자세히 보기
CSS 작성 조건

gallery-container의 너비를 1000px로 지정한다.
화면 가운데 배치한다.
제목은 가운데 정렬한다.
card-list는 display:flex를 사용한다.
카드는 가로 방향으로 나열한다.
카드 사이에는 간격을 준다.
각 카드의 너비를 300px로 지정한다.
카드에는 배경색, 테두리, 안쪽 여백을 적용한다.
카드 이미지는 너비를 100%로 지정한다.
버튼에는 배경색, 글자색, 테두리, 안쪽 여백을 적용한다.

css변수나 가상클래스 사용은 금지한다.
코드와 미리보기 만들어줘

HTML 작성 조건

전체 영역을 감싸는 div를 만들고 클래스명은 register-container로 작성한다.
입력 항목(아이디, 비밀번호, 이메일, 주소, 성별)은 한 줄씩 div로 감싸고, 클래스명은 form-row로 지정한다. 각 줄에는 label과 입력 요소를 함께 작성한다.
아이디 입력창 옆에는 "중복확인" button을 추가한다.
이메일은 아이디 부분 input, @ 텍스트, 도메인 선택 select로 구성한다. select의 option에는 naver.com, gmail.com, daum.net, 직접입력을 포함한다.
주소는 input(text)으로 작성한다.
성별은 radio 타입 input 2개(남성/여성)로 작성하고, name 속성을 동일하게 지정해 하나만 선택되게 한다.
하단에는 "회원가입" 버튼과 "취소" 버튼을 작성하고, 두 버튼을 감싸는 div의 클래스명은 button-group으로 지정한다.

예시 내용:
아이디: (입력칸) [중복확인]
비밀번호: (입력칸)
이메일: (입력칸) @ [드롭박스: naver.com / gmail.com / daum.net / 직접입력]
주소: (입력칸)
성별: ○ 남성  ○ 여성
버튼: [회원가입] [취소]
CSS 작성 조건

body에 배경색과 글꼴을 적용한다.
register-container의 너비를 500px로 지정하고 화면 가운데 배치한다.
form-row는 display:flex를 사용해 label과 입력 요소를 가로로 배치한다.
label의 너비를 일정하게 고정하여(예: 100px) 입력 요소들의 시작 위치를 맞춘다.
아이디 입력창과 중복확인 버튼은 가로로 나란히 배치하고 사이에 간격을 준다.
이메일의 아이디 입력창, @, 도메인 select도 가로로 나란히 배치한다.
성별 라디오 버튼 2개는 가로로 나란히 배치하고 사이에 간격을 준다.
button-group 안의 회원가입 버튼과 취소 버튼은 가로로 나란히, 가운데 정렬한다.
회원가입 버튼과 취소 버튼은 서로 다른 배경색으로 구분한다.
전체 박스에는 테두리, 배경색, 안쪽 여백을 적용한다.
