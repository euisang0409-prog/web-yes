카드 사이 간격은 20px로 한다.

학원 관리자 페이지의 대시보드 화면을 제작하시오.

요구사항
제목은 관리자 대시보드
통계 카드 4개를 Grid로 배치한다.
2열 2행 구조로 만든다.
각 카드에는 항목명과 숫자를 표시한다.
카드에는 흰색 배경, 테두리, 그림자 느낌을 적용한다.

문제

회사 소개 웹페이지의 기본 구조를 제작하시오.

요구사항
전체 화면은 Grid로 배치한다.
header, nav, main, aside, footer를 사용한다.
Header와 Footer는 전체 너비를 차지한다.
왼쪽에는 메뉴, 가운데에는 본문, 오른쪽에는 고객센터 영역을 배치한다.
열 구조는 180px 1fr 220px로 한다.

문제
학원 수강생 관리 시스템의 메인 화면을 제작하시오.

요구사항
화면은 Grid로 배치한다.
Header, Sidebar, Main, Footer 구조를 가진다.
Header는 전체 너비를 차지한다.
Sidebar는 왼쪽 메뉴 영역이다.
Main 영역 안에는 업무 카드 4개를 다시 Grid로 배치한다.
Footer는 전체 너비를 차지한다.
전체 레이아웃 열 구조는 220px 1fr이다.

문제
HTML 구조 조건

다음 구조를 반드시 포함하시오.

<header class="header">
    <div class="header-inner">
        <div class="logo"></div>
        <nav class="menu"></nav>
    </div>
</header>

<div class="container">
    <section class="banner"></section>
    <section class="products"></section>
</div>

<footer class="footer"></footer>
3. Header 작성 조건
.header
페이지 상단 영역이다.
흰색 배경을 적용한다.
아래쪽에 회색 테두리를 적용한다.
.header-inner
최대 너비는 1000px로 한다.
화면 가운데 정렬한다.
안쪽 여백은 20px로 한다.
Flex를 사용한다.
로고와 메뉴가 양쪽 끝에 배치되도록 한다.
세로 가운데 정렬한다.
.logo
텍스트는 ShopLogo로 작성한다.
글자 크기는 24px로 한다.
글자를 굵게 표시한다.
.menu
Flex를 사용한다.
메뉴 사이 간격은 20px로 한다.
메뉴 링크는 4개 작성한다.

메뉴명은 다음과 같다.

신상품
베스트
세일
고객센터
.menu a
밑줄을 제거한다.
글자색은 어두운 회색 계열로 지정한다.
4. 본문 영역 작성 조건
.container
최대 너비는 1000px로 한다.
화면 가운데 정렬한다.
위아래 여백을 적용한다.
5. Banner 작성 조건
.banner
특가 상품을 소개하는 영역이다.
배경색은 어두운 색으로 한다.
글자색은 흰색으로 한다.
안쪽 여백은 40px로 한다.
모서리를 둥글게 한다.
아래쪽 여백을 적용한다.
Banner 안에 포함할 내용
<h1>오늘의 특가 상품</h1>
<p>인기 상품을 특별한 가격으로 만나보세요.</p>
6. 상품 목록 작성 조건
.products
상품 카드를 감싸는 영역이다.
Grid를 사용한다.
한 줄에 상품 카드가 3개씩 배치되도록 한다.
상품 카드 사이 간격은 20px로 한다.

반드시 다음 속성을 사용한다.

display: grid;
grid-template-columns: repeat(3, 1fr);
gap: 20px;
7. 상품 카드 작성 조건
.product
상품 카드 6개를 작성한다.
각 상품은 <article class="product">로 작성한다.
배경색은 흰색으로 한다.
회색 테두리를 적용한다.
모서리를 둥글게 한다.
안쪽 여백은 20px로 한다.

각 상품 카드에는 다음 요소를 포함한다.

<div class="product-image">상품 이미지</div>
<h2>상품명</h2>
<p>상품 설명</p>
<p class="price">가격</p>
<button class="button">구매하기</button>
8. 상품 이미지 영역 조건
.product-image
실제 이미지는 사용하지 않고 회색 박스로 표현한다.
높이는 130px로 한다.
배경색은 밝은 회색으로 한다.
모서리를 둥글게 한다.
아래쪽 여백을 적용한다.
텍스트는 가운데 정렬한다.
세로 가운데 정렬을 위해 line-height: 130px;를 사용한다.
글자색은 회색 계열로 한다.
